GetNetDirect v11.4 - Existing Account Temporary Password Reset

THIS DOES NOT CREATE A NEW PROFILE.

Admin workflow:
1. Admin Portal > Team & Referral Partners.
2. Find the EXISTING employee, contractor, leasing office, realtor, or referral partner.
3. Click Reset Password.
4. Click Generate Temporary Password.
5. Click Save Temporary Password.
6. Click Copy Temporary Login and give those credentials to the user.
7. The user's current sessions are revoked.
8. The user signs in using the temporary password.
9. Before the portal opens, the user is forced to create their own new password.
10. After saving their new password, they continue into the SAME existing profile.

The old password is not required and is never displayed.
Existing lead assignments, referral history, QR code, payout history, and profile ID remain attached to the same account.
