GetNetDirect v11.3 - Set / Reset Login

Admin can now clearly reset an employee, contractor, or referral partner password even when the user forgot the old password.

Admin flow:
1. Log in as Admin.
2. Open Team & Referral Partners.
3. Find the account.
4. Click Set / Reset Login.
5. Type a new password (8+ characters) OR click Generate New Password.
6. Optionally check Require password change at next login.
7. Click Save / Reset Login.
8. Give the user the new credentials.

The user's old password is not required and is never displayed.
