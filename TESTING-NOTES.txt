IMPORTANT LIMITS
The tests use simulated customers, mocked network responses and a fake database
adapter. Chromium rendered the actual HTML/CSS/JS inline; external URL navigation
was not used. No live accounts, leads or payouts were created/changed for testing.
The API handler tests are not an actual PostgreSQL migration/SQL integration test.
The existing external QR library/physical QR scan and real carrier ordering were
not retested offline. This is not an exhaustive accessibility, security, stress or
Safari/iPad-hardware certification. The updated frontend/API must be deployed and
checked together with a fresh two-device referral test before broad rollout.
